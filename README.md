# Distrito Alem · Tableros de gestión

Tableros estáticos (HTML con los datos incluidos), publicados con GitHub Pages.

| Archivo | Contenido |
|---|---|
| `index.html` | Tablero general: estado de resultados mensual (ventas, mercadería, sueldos + cargas, resultado bruto, otros gastos, resultado neto), en vista total, fiscal y no fiscal, con % sobre ventas. |
| `ventas.html` | Tablero de ventas 2026 (exportaciones de Fudo). |
| `compras.html` | Tablero de compras y gastos (cruce Fudo / ARCA). |

Desde el tablero general, los nombres de Ventas, Mercadería, Sueldos + cargas y Otros gastos abren el tablero de detalle; en ventas y compras, el botón «← Tablero general» vuelve al inicio.

## Actualizar

Reemplazar el archivo correspondiente manteniendo el nombre (`ventas.html`, `compras.html`) y volver a generar `index.html` con los datos nuevos.
